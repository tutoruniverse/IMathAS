Macro Library diff

A library of diffing functions for identifying differences.

  • diffbychar
  • diffbycharhtml
  • diff

diffbychar

diffbychar($old,$new)

Given two strings, compares them by-character to determine changes.

Returns an array containing the character if no change, and an array with index 'd' for deletions and 'i' for insertions if changed.

Examples
diffbychar("3+2xy+5","3+45xy")
// [3,"+",['d'=>[2],'i'=>[4,5]],"x","y",['d'=>["+",5],'i'=>[]]]

diffbycharhtml

diffbycharhtml($old,$new,[$format])

Given two strings, compares them by-character to determine changes.

format: 1: show inserts, 2: show deletions, 3: show both

Returns an html string, with insertions wrapped in <ins> tag, and deletions marked in <del> tag.

Examples
diffbycharhtml("3+2xy+5","3+45xy") // 3+<del>2</del><ins>45</ins>xy<del>+5</del>
diffbycharhtml("3+2xy+5","3+45xy",2) // 3+<del>2</del>xy<del>+5</del>
diffbycharhtml("3+2xy+5","3+45xy",1) // 3+<ins>45</ins>xy

diff

diff($old,$new)

Given two arrays, compares them by-entry to determine changes.

Returns an array containing the entry if no change, and an array with index 'd' for deletions and 'i' for insertions if changed. diffbychar uses this function, with the input strings split by character. If you'd prefer to split a different way, you can use this function directly.
